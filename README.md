# Ingrid_introduction_page

A simple personal introduction page created as part of the PRO1001 Frontend Essentials course. 

##About the project:
This project was created to practise basic HTML and CSS, Flexbox, forms, responsive design, and Git/GitHub workflow.

##The page includes:
- Navigation menu
- A personal introduction - Om meg
- Interests and fun facts - Interesser og Fun facts
- A contact form with HTML5 validation - Kontakt meg
- Responsive layout for smaller screens

##Technologies:
- HTML5
- CSS3
- Flexbox
- Git
- GitHub

##Project structure:

- index.html – The main HTML page
- style.css – Styling and responsive design
- ingrid.jpg – Profile image
- .gitignore – Files and folders excluded from Git
- LICENSE – MIT License
